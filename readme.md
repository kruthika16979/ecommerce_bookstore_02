# ecommerce bookstore - cart module

This branch is dedicated to improving and finalizing the README for the project.  

## Features of the Cart Module
- Add books to shopping cart
- View, update, and remove items
- Responsive design for desktop and mobile
- Checkout page with form validation

## Project Branches
1. cart-ui – User Interface of cart
2. cart-js – JavaScript functionality
3. cart-style – Styling of cart page
4. cart-final – Combined features and checkout
5. cart-readme – README improvements and documentation

## How to Use
1. Open `cart.html` to interact with the cart system
2. Add books to cart, adjust quantities
3. Proceed to `checkout.html` to place the order
