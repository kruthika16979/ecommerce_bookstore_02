E-commerce bookstore Cart Project

This project is a simple, responsive shopping cart system built using **HTML**, **CSS**, and **JavaScript**.  
It demonstrates how to create and style a checkout page, validate form inputs, and manage cart data.

Features
- 🛒 **Cart Page** – Displays selected products.
- 📦 **Checkout Page** – Collects user details and order information.
- 🎨 **Responsive Design** – Works on desktop and mobile devices.
- ✅ **Form Validation** – Ensures all required fields are completed before submission.
- 📄 **Clean Structure** – HTML, CSS, and JavaScript in separate files.


 Branch Structure
1. **master** – Base project setup.  
2. **cart-final** – Final integrated branch with all features.  
3. **cart-ui** – Checkout page design and layout improvements.  
4. **cart-style** – Styling for the checkout page in `checkout.css`.  
5. **cart-js** – JavaScript for checkout form validation and interactivity.  
6. **cart-readme** – Contains this README documentation.
